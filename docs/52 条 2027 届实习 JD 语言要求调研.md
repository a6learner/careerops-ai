### 通用 SWE vs 后端专门 vs AI/ML 岗位

- **通用 SWE 实习（大公司）**：几乎 100% 是"任选其一"。Amazon 全部 5 条通用 SDE 实习都是同一句模板 "at least one general-purpose programming language such as Java, Python, C++, C#, …"；Google 通用实习是 "one of the following … including but not limited to: C, C++, Java, or Python"；Microsoft 干脆只要求 "one year of programming experience in an object-oriented language"，不点名任何语言。**没有任何一条大公司通用 SWE 实习 JD 硬性要求 Java。**
- **后端专门岗（本次读到 6 条）**：语言要求明显更具体，而且方向分裂——企业/JVM 系点名 Java（Workiva 后端服务用 Java、Delsys "fluent in Java, C#, or C++"、TikTok 变现平台 Java + Spring Boot）；安全/AI/Web 初创点名 Python/Go/TS（Prophet Security "Python or Go"、Nebo "Ruby on Rails/Node"、N1 "Rust, C, C++, Zig"）。Spring / Spring Boot 只在 3 条 JD 出现（TikTok、Tesla InfoSec、AMD 的"加分"清单），Django/FastAPI/Flask 出现在 2 条（AMD、Tesla InfoSec），Node.js 出现在 2 条（Notion ×2、Nebo）。
- **AI/ML 岗（5 条）**：Amazon Applied Science 实习 "Python preferred"；Google Content Safety "Python or C++" + LLM/transformers；Microsoft 两条 AI 实习不点名语言但偏好 PyTorch/TensorFlow/scikit-learn（事实上的 Python 生态）；例外是 Ericsson 的 "AI Software Engineer Intern" 和 TikTok 的 "AI Agent" 实习——它们是**工程/平台向的 AI 岗，反而点名 Java**（Ericsson 把 C/C++/PL/I 遗留代码重编译成 Java；TikTok 偏好 Java + Spring Boot）。
- **数据/量化**：Capital One 数据科学实习（Python/R/SQL）、Garda Capital（Python + 一门静态类型语言）→ Python 主导；但 IMC Trading 的低延迟 SWE 实习是 "Java or C++ preferred"，而其 Python 岗单独列为 "Quantitative Developer - Python"。

### 明确说"语言不重要，看基础"的 JD（4 条）

1. **Stripe**（实习）："We work mostly in Java, Ruby, JavaScript, Scala, and Go. **We believe new programming languages can be learned if the fundamentals and general knowledge are present**"。
2. **Notion**（实习）："**Not ideological about technology: To you, technologies and programming languages are about tradeoffs… you're not ideological and can learn new technologies as you go**"。
3. **Zip**（实习）："**Ability and interest to quickly learn new frameworks, architecture patterns, and programming languages as needed**"；技术栈要求写成 "…, or ability to learn these technologies"。
4. **Microsoft**（4 条实习）：要求只写 "one year of programming experience in an object-oriented language"，完全不点名语言，等价于"语言不限"。

### 关键结论

1. **Python 的覆盖率高于 Java**（73% vs 56%），但差距主要来自 AI/ML、数据科学、编译器/系统脚本、Web 初创这些"点名 Python"的细分岗；在"任选其一"的通用清单里两者几乎总是同时出现（23/52 条同时提到）。
2. **大公司通用 SWE 实习基本"语言不限"**：Amazon/Google 的模板都是"至少掌握一门通用语言（如 Java、Python、C++、C#）"，Microsoft 连语言都不点名。为这类岗位准备时，选一门自己最熟的语言把数据结构/算法/系统设计练到面试可用，比纠结 Java 还是 Python 更重要。
3. **硬性要求 Java 的是有限且可预测的细分领域**：Android/移动（Google Wallet 的 Java/Kotlin）、企业级/JVM 后端（Workiva、Delsys、TikTok 变现平台 + Spring Boot）、低延迟交易（IMC "Java or C++"）、保险/传统金融 IT（New York Life 的 C/C++/Java/C#、The Hartford 的 Java/Python/C#/.NET）。想进这些方向，Java + Spring Boot 是明确的敲门砖。
4. **硬性要求 Python 的领域同样清晰**：AI/ML 与研究岗（Amazon Applied Science、Google Content Safety、Microsoft AI 实习的 PyTorch/TF 偏好）、数据科学/量化研究（Capital One、Garda）、平台/工具与安全自动化（Prophet Security 的 Python/Go、Tesla 诊断自动化的 Python/Golang、Google 编译器岗的 C++ + Python）。
5. **实务建议**：以 Python 作为"面试与 AI/数据方向"的主语言覆盖面最广；若目标包含金融/企业后端或 Android，则需要额外补一套 Java + Spring Boot 的项目经验（本次样本中，"只要 Java 不要 Python" 的 6 条全部落在这些方向）。同时注意 Go/TypeScript 在初创后端 JD 中出现频率不低（Go 出现在 Google、Palantir、Micron、Prophet、Lightcast、Stripe、Workiva、Tesla 等 8 条），Java/Python 之外可留一门作为差异化。
